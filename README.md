# TariffLens - HS코드 관세 & FTA 실효세율 비교기

> **품목별 기본세율(A)·양허세율(C)·FTA 협정세율 비교 및 관세 절감 시뮬레이션 웹앱**

사용자가 **HS코드(6자리·10자리)** 또는 **품목명(한글·영문)**을 검색하면 기본세율(`A`), WTO 일반양허세율(`C`), 주요 협정별 FTA 협정세율(`FUS`, `FEU`, `FCN`, `FRC`, `FVK`, `FCL`)을 한눈에 비교하여 **관세법 제50조 우선순위에 따른 최적 실효세율**을 자동 도출하고, 수입 금액(CIF)에 따른 **예상 관세·부가가치세(10%) 및 절감액**을 실시간으로 계산합니다.

---

## 주요 기능

- **중앙 검색 바 및 추천 해시태그**
  - 6자리/10자리 HS코드(점 `.` 유무 무관) 및 한글·영문 품목명 자동완성 검색
  - `#볶은커피`, `#마스크팩`, `#리튬이온배터리`, `#와인`, `#자동차기어박스`, `#반도체노광장비`, `#냉동삼겹살`, `#산업용로봇` 원클릭 시나리오 태그 제공
- **관세법 제50조 기준 최적 실효세율 자동 판정**
  - WTO 양허세율이 기본세율보다 높은 농림축산물(예: 볶은 커피 WTO 54% > 기본 8%)은 C/O 미구비 시 기본세율 우선 적용
  - WTO 양허세율과 FTA 협정세율이 동일하게 최저(0%)인 품목(예: 반도체 노광장비)은 원산지증명서(C/O) 발급 및 사후검증 부담이 없는 비협정 세율을 최적 1순위로 자동 추천
- **세율 비교 테이블 및 코드 범례 툴팁**
  - 세율 종류, 코드(`A`·`C`·`F` 마우스 오버 툴팁 지원), 세율(%), 원산지증명서(C/O) 필요 여부, 절감폭(`%p`) 비교
  - 원하는 행 클릭 시 우측 시뮬레이터에 즉시 반영
- **실시간 관세 & 부가가치세(10%) 시뮬레이터**
  - 수입 과세가격(CIF) 레인지 슬라이더 + 직접 입력 지원 (원화 `KRW` 및 외화 `USD`/`EUR`/`CNY`/`JPY`/`VND` + 환율 모드 전환)
  - 총 관세액, 부가가치세 `(과세가격 + 실효관세) × 10%`, 예상 절감 세액 실시간 산출

## 프로젝트 파일 구조

```text
.
├── index.html                    # React 18 + Tailwind CSS + Lucide 아이콘 통합 웹앱
├── server.js                     # 외부 의존성 없는 Node.js 내장 모듈 정적 로컬 서버
├── start-server.bat              # Windows 원클릭 로컬 서버 구동 배치 스크립트
├── package.json                  # npm start 스크립트 설정
├── vercel.json                   # Vercel 정적 호스팅 무설정 배포 규격
├── .nojekyll                     # GitHub Pages 정적 파일 그대로 서빙 설정
└── .github/workflows/deploy.yml  # GitHub Pages 자동 배포 워크플로우
```

---

## 로컬 실행 방법

1. **브라우저 직접 실행:** `index.html` 파일을 더블 클릭하여 바로 열기
2. **Node.js 로컬 서버 실행:**
   ```bash
   node server.js
   # 브라우저에서 http://localhost:3000 접속
   ```

---

## 웹 배포 방법 (GitHub Pages)

1. GitHub에서 새 저장소(Repository)를 생성하고 본 폴더의 파일들을 업로드(`main` 브랜치 푸시 또는 웹 드래그 앤 드롭 업로드)합니다.
2. 저장소 상단 **Settings** → 좌측 **Pages** 메뉴로 이동합니다.
3. **Build and deployment > Source**를 **GitHub Actions**(또는 **Deploy from a branch** → `main` / `/ (root)`)로 선택하면 약 30초 내외로 `https://<GitHub아이디>.github.io/<저장소이름>/` 주소에 무료 배포됩니다.
